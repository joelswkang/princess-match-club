Princess Math Club — v1.6 (v1.5 design + Capsules & Collection)

This version restores the original v1.5 main screen and game layout. It adds only the Magical Capsules, Princess Collection Book, and My Princess accessory inventory to that screen.

Included:
- v1.5 main screen, child selection, learning settings, timed questions, and landscape game layout
- Existing monthly sticker cap (20 per child each month), sticker display, progress records, and monthly history
- Earn 1 capsule for every 10 completed questions; skipped questions do not count
- 50-princess collection book and accessory inventory/equipping
- Separate reward data for Leah and Lena, saved locally under the existing pmc-rewards-v1-* keys
- Existing settings and records remain on this device; no cloud sync

Deploy safely:
1. Unzip this package.
2. In the SAME existing GitHub Pages repository, replace the root index.html and manifest.json with these files.
3. Do not create a new repository or change the GitHub Pages URL.
4. Do not clear Safari website data or localStorage; that can erase saved settings and records.

The layout was syntax-checked, but not physically tested on an iPhone in this session.
